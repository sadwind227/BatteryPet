# 资源占用记录

本文数字来自 v0.4.2 的空闲采样。v0.5.0 新增蓝牙独立查询进程，最多运行约 12 秒，未量化该进程的 CPU/内存峰值；不得将下表当作新版完整查询周期的占用。

测量日期：2026-11-02。Windows 电脑有 20 个逻辑处理器；使用当前 Release 构建，每秒采样一次，共 20 个样本。下表是启动 3 秒后约 19 秒的空闲阶段，测试结束后已关闭临时进程。原始采样在 `artifacts/perf-refresh/`。

| 场景 | CPU 时间增量 | 平均 CPU | 工作集平均 / 峰值 | 私有内存平均 / 峰值 |
| --- | ---: | ---: | ---: | ---: |
| 仅托盘静默运行 | 0 秒（低于采样分辨率） | 接近 0% | 51.2 / 51.3 MiB | 11.2 / 11.3 MiB |
| 演示模式、桌宠动画开启 | 1.062 秒 / 19.21 秒 | 单个逻辑处理器的 5.53%，整机 20 核容量的 0.277% | 62.6 / 63.9 MiB | 17.5 / 19.1 MiB |

GPU：本机 Windows 性能计数器没有提供 `GPU Engine` 进程级对象；NVIDIA `pmon` 采样也未列出 BatteryPet。无法据此报告准确的进程 GPU 百分比或集成显卡占用。全局显卡利用率包含其他程序，不能算到 BatteryPet 名下。

这些数字代表空闲托盘和默认桌宠动画，不代表自定义大图/GIF、多个扩展适配器或成功的真实硬件读取。本自动化会话枚举到 C547 接收器，但打开 HID 接口受到 Windows 错误 5 限制，因此未测到真实轮询期间的资源峰值。桌宠动画通过 50 毫秒 WinForms 计时器重绘；隐藏桌宠时计时器停止。
