# 电量桌宠 · 0.4.1 桌面边界修复

Windows 10/11 的本地托盘电量工具，附带自绘小鲸鱼桌宠。托盘数字仍保持像素风。当前硬件适配范围为罗技 C547 接收器上的 HID++ 2.0 统一电量特性（0x1004），查询槽位 1、2。

## 启动

打开 `发布版\BatteryPet.exe`。需要电脑已安装 .NET 8 Desktop Runtime 和 Python 3.10+；优先从 Python 注册信息定位解释器，找不到时再使用 PATH。本机具备这些环境。这是免安装的框架依赖版本，暂未捆绑运行环境；请保留发布文件夹中的全部文件。普通启动会显示面板，并按设置显示桌宠；启用静默启动后只驻留托盘。右键桌宠或点击管理托盘图标可随时打开面板。

- 左键点击设备托盘图标刷新电量；本阶段共用接收器统一刷新。
- 右键图标选择数字、圆环、电池样式，打开面板或切换桌宠显隐。
- 管理托盘图标打开设备面板；关闭面板仍继续运行，退出使用托盘菜单。
- 数字为加大像素风，按系统托盘实际尺寸绘制，增加深色描边以适应深浅任务栏；低于用户阈值变红，其他区间为黄/绿。100 使用等高紧凑布局；数字样式充电时显示底部白色短线，其他样式保留右上角状态点。
- 面板可设置每设备阈值 1–100%、提醒开关和托盘显隐。严格低于阈值才提醒，每个低电量区间去重；改变阈值后使用当前新鲜读数重新判断。
- 桌宠平时只显示角色，**左键点击才显示电量气泡**，并刷新读数；默认 6 秒后自动收起，点击气泡也可收起。后台刷新和悬停都不会主动弹出电量。
- 按住左键拖动，松手保存位置；拖动不算点击。悬停会微笑，点击有轻弹与爱心，拖动改变表情，平时有呼吸、眨眼动画。
- 拖动过程中实时限制在屏幕工作区内，不会被拖到屏幕或任务栏外；跨屏时按鼠标所在屏幕限制位置，拖动被中断时也会校正边界。
- “桌宠外观”页可设置 60%–180% 大小、薄荷海/晴空蓝/暮光紫配色、3–15 秒气泡停留、动画及置顶开关，设置即时生效并保存。
- 右键桌宠也可选择大小与配色、打开设备面板、回到右下角或隐藏；Ctrl + 滚轮可调整大小（取决于系统的非活动窗口滚动设置，面板滑块始终可用）。
- 每 60 秒刷新。失败保留旧值并置灰，不冒充当前值。

## 启动与素材

面板中的「启动与素材」页提供以下选项，内容较多时向下滚动：

- **开机自启动**：用户主动开启后，在当前用户登录 Windows 时启动。默认关闭，不要求管理员权限；取消选中时只删除本程序的启动项。若移动了程序目录，请在新位置重新设置。
- **静默启动**：下次启动生效，仅显示托盘，不弹主面板、不显示桌宠；不会清除原有角色和位置，也不会关闭低电量提醒。从托盘「显示桌宠」即可恢复。也可使用 `BatteryPet.exe --silent` 临时静默启动。
- **导入图片**：支持透明 PNG、JPG、GIF、BMP，保持比例缩放。文件会复制到应用数据目录，原文件移动后仍可使用。单文件上限 20 MB、1600 万像素、单边 8192 像素，GIF 最多 300 帧。关闭动画时 GIF 显示首个可见帧。
- **恢复内置角色**：立即回到自绘小鲸鱼。自定义图片只使用图片本身及本程序的轻微呼吸、点击弹动和拖动反馈，不会自动生成五官表情或加载第三方骨骼系统。
- **使用随附角色**：一键使用项目维护者提供的像素风鲸鱼女仆角色图。图片来源和适用范围见 `Examples\CustomPet\SOURCE.md`。
- **导入点击音效**：支持 WAV/MP3，导入时检查格式与 Windows 解码能力；单文件最多 20 MB。启用后仅点击角色时播放，拖动、启动及后台刷新不播放。每次最长 10 秒，连续点击重新播放；可试听/停止或恢复自制的默认轻触音。点击音效默认关闭。

图片和音效导入后立即保存。损坏或丢失的自定义图片回退到内置角色；不可用的音效不会阻止电量刷新和桌宠运行。静默启动与开机启动相互独立，可分别选择。

## 设备适配

新增「设备适配」页，可发现已安装程序、手动选择 EXE/资源目录，提取脚本和 ASAR 中的电量线索，再导出到已有 agent 工作区。

- Codex、Claude Code、DeepSeek Harness、Hermes 提供已核实形式的 CLI 一行命令；使用前需该 CLI 已安装、登录且支持相应参数。
- WorkBuddy 和其他桌面 agent 使用通用任务包，软件生成一行工作区指令，不编造未确认的 CLI 参数。
- 导回 `candidate.json` 后可只读试读。当前扩展支持厂商 HID Feature 读取/被动 Input，不执行导入代码或未知准备帧；两个不同真实电量值都与对照一致后才能启用。
- 已有罗技 C547 继续由内置 HID++ 采集；此功能不保证从任意原生/加密客户端自动逆向出协议。

完整流程、可复制任务包和命令说明见 [设备适配说明](DEVICE_ADAPTATION.zh-CN.md)。

## 配置与数据

设置存于 `%LOCALAPPDATA%\BatteryPet\settings.json`，不上传任何设备信息。本阶段配置原子保存，尚未实现历史备份与损坏配置提示。

导入素材存于 `%LOCALAPPDATA%\BatteryPet\assets`，恢复默认不会删除用户的原始文件。开机启动仅由用户切换设置时写入当前用户的 `Run` 项，不在每次启动时强行重新注册。依据：[Microsoft 登录启动项说明](https://learn.microsoft.com/en-us/windows/win32/setupapi/run-and-runonce-registry-keys)。

## 开发与验证

```powershell
dotnet build -c Release
python -m unittest test_provider.py -v
python -m unittest test_adaptation.py -v
python battery_bridge.py
发布版\BatteryPet.exe --ui-check
发布版\BatteryPet.exe --adapt-check
```

模拟界面可以使用 `BatteryPet.exe --demo` 启动，明确标注为模拟数据，不代表真实硬件支持；正常模式不使用模拟电量。演示模式使用独立配置，不覆盖真实设备设置，不实际修改开机启动项。`--ui-check` 在程序目录生成渲染检查图与交互测试结果，不读鼠标、不更改系统启动项、不播放测试音频。

## 已验证与限制

- 2026-11-02：通过原始 HID++ 诊断脚本实机识别 G502 X LIGHTSPEED，读取到 86%、放电状态。
- 自动化受限环境打开 HID 可能返回拒绝访问；从正常 Windows 桌面运行无需因此默认要求管理员权限。
