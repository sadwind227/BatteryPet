# 安装与升级

当前安装版为 Windows x64、0.6.1-dev 开发预览版。安装程序无需管理员权限。

## 从旧版升级

1. 在原 Windows 账户中，从托盘菜单退出旧版电量桌宠。
2. 下载并运行 `BatteryPet-v0.6.1-dev-Setup.exe`，确认安装。
3. 安装完成后启动，或从开始菜单打开“电量桌宠”。旧程序目录保留，以便回退。

设备适配不需要重新生成。程序继续读取 `%LOCALAPPDATA%\BatteryPet`，包括 `settings.json`、`adapters\enabled`、`adapters\verification` 和 `assets`。安装程序不会用发布包覆盖这些数据。已验证的自定义 HID 协议继续由原有运行时读取；本次未更改 schema_version=1。

安装前会复制现有数据至 `%LOCALAPPDATA%\BatteryPet-Backups\时间戳`，同时记录原开机启动命令、开始菜单快捷方式和新安装位置。备份失败会终止安装。请保存备份，其中可能包含个人设备信息，不要作为公开发布包分享。

程序安装在 `%LOCALAPPDATA%\Programs\BatteryPet\版本-时间戳`。每次安装使用独立目录，保留旧程序。原本开启了开机启动的账户会更新为新程序；原本未开启的不会自动开启。旧版手动创建的桌面快捷方式不会更改，请使用新的开始菜单入口。

## 运行环境与兼容范围

应用仍需要 .NET 8 Desktop Runtime（x64）和 Python 3，安装包没有捆绑这些环境。已经能运行旧版的用户通常已有所需环境；新电脑需先按 README 安装。本安装包尚未进行代码签名，Windows 可能显示未知发布者提示。

此升级针对同一台电脑、同一 Windows 账户及使用上述数据目录的旧版。已对工作区保留的旧版适配运行时核对，并测试备份时完整保留适配和验证记录；尚未在外部用户电脑及未知更早版本上实测。外部程序目录中的私人脚本、不同 Windows 账户及非标准配置位置不自动迁移。

## 回退与移除

回退前退出新版，直接运行保留的旧版 BatteryPet.exe；如需开机启动，在旧版设置中重新开启。若需要恢复数据，先退出所有版本，另行保存当前 `%LOCALAPPDATA%\BatteryPet`，再从对应备份的 data 目录恢复。

移除时退出程序，在设置中关闭开机启动，删除开始菜单中的“电量桌宠”快捷方式及对应安装目录即可。个人数据和备份保留，由用户决定是否删除。此版本未注册 Windows“已安装的应用”卸载入口。

## 维护者构建

运行 `scripts/build-installer.ps1`，先生成经过审核的便携版，再将其嵌入 EXE。安装器使用 Windows 自带 .NET Framework 4 编译器。构建后自动在独立测试目录提取内嵌包、验证模拟适配及验证记录备份，不修改真实用户数据和注册表。


## 0.6.1-dev 桌宠边界
角色可见范围左右各预留一个系统滚动条宽度，上下贴可用区域、避开任务栏。透明窗口允许越过边缘。气泡独立向内调整，不移动桌宠；副屏负坐标继续保存。支持按显示器 DPI 调整。布局回归截图位于发布检查记录，不含真实设备电量。
