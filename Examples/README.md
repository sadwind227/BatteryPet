# Custom pets / 自定义桌宠

BatteryPet includes a programmatically drawn whale and an optional maintainer-created sample image. The sample's separate [provenance and bundle scope](CustomPet/SOURCE.md) accompanies it.

内置角色由程序绘制；另附维护者制作的示例图，来源与随包授权见 [SOURCE.md](CustomPet/SOURCE.md)。

Use **启动与素材 → 导入图片** to import PNG, JPG, GIF or BMP. Imported images remain local. Please use images that you are permitted to use and redistribute only when their rights allow it.
